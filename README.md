# Quanti playbooks

Step-by-step guides that Claude runs with you, on top of the Quanti connector.

## Install

In claude.ai, Claude Desktop or Cowork: **Customize > Plugins > Add > Add marketplace**,
then enter `quantiio/quanti-playbooks`. Pick the playbooks you need from the list.

## Available playbooks

| Plugin | Status |
|---|---|
| `quanti-smoke-test` | Internal test plugin (staging), not for clients |

Migration playbooks for server-side Google Tag Manager are in preparation.
